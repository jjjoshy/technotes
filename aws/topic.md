# AWS Topics for Beginners

## Fundamentals

- AWS account setup, billing alerts, and free tier
- Regions and availability zones
- IAM users, groups, roles, and policies
- Shared responsibility model
- AWS CLI and basic infrastructure concepts

## Core Compute and Networking

- EC2 basics
- Elastic IP and key pairs
- Security groups and network ACLs
- VPC, subnets, route tables, and internet gateways
- Elastic Load Balancer
- Auto Scaling

## Storage and Databases

- S3 buckets and storage classes
- S3 lifecycle rules and bucket policies
- EBS volumes and snapshots
- RDS
- DynamoDB basics

## Applications and Operations

- AWS Lambda
- API Gateway
- CloudWatch metrics, logs, alarms, and dashboards
- CloudFormation or Terraform basics
- Secrets Manager
- Route 53
- Common AWS cost optimization practices

## Suggested Project Order

1. Host a static website in S3.
2. Create a VPC with public and private subnets.
3. Deploy a web server on EC2 with a security group.
4. Configure an Application Load Balancer and Auto Scaling.
5. Build a serverless API using API Gateway, Lambda, and DynamoDB.
6. Add monitoring, logs, alarms, and billing alerts.
7. Deploy the infrastructure using CloudFormation or Terraform.
